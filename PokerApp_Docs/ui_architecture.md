# Архитектура Интерфейса (UI/UX) — Poker Preflop App

Данный документ описывает визуальную структуру, иерархию компонентов и применяемую дизайн-систему. Он предназначен для сравнения визуальной и структурной части приложения с аналогичными покерными проектами (чартами, тренажерами).

## 1. Визуальная иерархия (Component Tree)
Пользовательский интерфейс построен по модульному, компонентному принципу на базе React.

```text
<App> (Корневой контейнер, управляет общим Layout)
 ├── <Header> (Логотип, описание)
 ├── Левая колонка (Контролы управления)
 │    ├── Mode Toggle (Кэш / MTT)
 │    ├── <ScenarioSelector> (Выбор RFI / Vs RFI / 3-Bet Push)
 │    │    └── Меню VillainPos (Появляется только если выбран Vs RFI)
 │    ├── Меню HeroPos (Выбор нашей позиции UTG-BB)
 │    └── <StackSelector> (Выбор глубины стека от 8bb до 200bb)
 └── Правая колонка (Зона визуализации)
      ├── Инфо-панель (Выбранные параметры: Режим, Позиции, Стек)
      ├── <PokerGrid> (Сетка рук 13x13)
      │    ├── 169x Ячеек рук (Combos)
      │    └── Tooltips (Всплывающие подсказки при наведении)
      └── Легенда (Цветовая расшифровка матрицы)
```

## 2. Layout System (Сетка и Адаптивность)
Проект использует **Tailwind CSS** для построения гибких (Responsive) интерфейсов, работающих как на мобильных устройствах, так и на десктопе.

*   **Глобальный контейнер:** `max-w-6xl` (Ограничение ширины для удобочитаемости на ультра-широких мониторах).
*   **Grid Framework:** На десктопе (`lg:`) используется `grid-cols-12` (12-колоночная сетка).
    *   Левая колонка с фильтрами занимает **4 колонки** (`lg:col-span-4`).
    *   Матрица рук (PokerGrid) занимает **8 колонок** (`lg:col-span-8`).
*   **Мобильная версия:** На экранах телефонов колонки выстраиваются вертикально (`grid-cols-1`). Сначала идут контролы, затем сама матрица.
*   **Сама матрица PokerGrid:** Жестко фиксированная сетка `gridTemplateColumns: repeat(13, minmax(0, 1fr))` с сохранением квадратных пропорций (`aspect-square`).

## 3. Design System & Tokens (Дизайн-система)
Интерфейс использует современный "Dark Mode Glassmorphism" стиль, что выгодно отличает его от устаревших интерфейсов многих покер-румов и старых тренажеров.

### Базовые цвета (Dark Theme)
*   Фон приложения: `bg-zinc-900` (Глубокий темный).
*   Панели (Карточки): `bg-zinc-800/40` с размытием заднего фона (`backdrop-blur-md`). Создает эффект "матового стекла".
*   Границы карточек: Деликатные бордеры `border-zinc-700/50` и мягкие тени `shadow-xl`.

### Семантическая палитра (Цветовое кодирование логики)
Цвета строго привязаны к покерным действиям. Это важнейший UX-паттерн приложения.
*   **Изумрудный (Emerald-600):** RFI (Открытие рейзом).
*   **Красный (Red-600):** Push (Олл-ин).
*   **Синий (Blue-600):** Call (Колл/Защита).
*   **Оранжевый (Orange-600):** 3-Bet (Рейз против чужого RFI).
*   **Штриховка (Паттерны):** Для миксованных стратегий (например, 50% RFI / 50% Fold) используется диагональная `repeating-linear-gradient`.
*   **Градиент (Оранжево-Синий):** Для миксов (3-Bet / Call).

### Акценты меню (Stack Selector)
Группы стеков окрашены по-разному, чтобы пользователь интуитивно понимал, в какой "зоне" он находится:
*   Глубокие стеки (>40bb): Серый (`slate`).
*   Средние стеки (25-35bb): Синий (`blue`).
*   Шорт-стек (20-24bb): Фиолетовый (`violet`).
*   Пуш/Фолд (≤19bb): Янтарный (`amber`).

## 4. Паттерны взаимодействия (Micro-interactions)
*   **Hover-эффекты сетки:** При наведении мыши на ячейку руки (`hover:scale-110`), она слегка увеличивается и выходит на передний план (`z-20`), отбрасывая цветную тень.
*   **Тултипы (Tooltip):** Абсолютно позиционированные всплывающие окна, показывающие точную долю микса (например: "Микс 65% RFI") при наведении.
*   **Плавные переходы (Transitions):** Все переключения (смена активных кнопок позиции, режима) анимированы: `transition-all duration-300`.

## 5. Связь State и UI (Inversion of Control)
Переход на Zustand архитектурно изменил UI-слой:
1.  **Store (`usePokerStore.js`):** Хранит `mode`, `stack`, `scenario` и т.д.
2.  **Helper (`utils/gridStyles.js`):** "Выкачивает" из Store текущие стейты, скрещивает их с тяжелой матрицей `rangesGenerator.js` и выплевывает **готовые CSS-классы и стили**.
3.  **UI (`PokerGrid.jsx`):** Является "глупым" компонентом (Dumb Component). Он больше не считает покерную математику. Он просто рендерит 169 `<div>` элементов и слепо применяет к ним стили, которые ему выдал `gridStyles.js`. Это обеспечивает безупречно быстрый рендеринг при кликах по стекам и позициям.
